# field-kit · 线马直线电机作战速查（手机端）

一个单文件静态页，给销售在客户现场用的**速查 + 当场测算**工具。不含任何客户资料。

## 里面有什么

| 页签 | 用途 |
|---|---|
| 参数 | DB 9 型号、DF 4 型号官方推力；EL/EH、PIC 一句话定位 |
| 话术 | 30 秒开场四段、三套逐字稿（DB-DF / EL-EH / PIC）、8 种拒绝应对 |
| 成本测算 | 三年 TCO 计算器：输入推力与导轨价格，自动算「免吸力能省多少、几个月补回差价」 |
| 交期 | 10 天 / 20-30 天 vs 行业 25-60 天 vs 进口 3-6 个月 |

## 怎么在手机上打开

1. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` / root → Save
2. 等 1 分钟，访问 `https://001542.github.io/field-kit/`
3. 手机浏览器打开后「添加到主屏幕」，以后一点就开

也可以直接把这个 `index.html` 发到微信文件传输助手，手机浏览器打开，离线可用。

## 改内容

直接在 GitHub 网页上编辑 `index.html`，提交即生效（Pages 会自动重建）。
- 改型号参数：搜 `MIC98`，改表格里的数字
- 改话术：搜「逐字稿」
- 改测算默认值：搜 `i_thrust`
